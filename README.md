# heygemm

Browser games — no install, no accounts. Click and play.

**Live:** https://YOUR-USERNAME.github.io/heygemm/

## Features

- Difficulty (Easy / Medium / Hard) on most games
- Local leaderboards (best score per name, top 10)
- Works on desktop browsers
